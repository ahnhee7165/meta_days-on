# DAYS ON 통합 광고 성과 대시보드

`index.html` 파일 하나로 완결된 대시보드입니다. 더블클릭하거나 브라우저 드래그로 바로 열립니다.

## 구성
- 표지·요약: 전체 채널(META 협력/외부, 구글, 네이버 SA/GFA, 애드부스트) 통합 KPI
- 채널별 리포트 6개: 원본 구글시트의 요약(월별·주차별·일자별)/세부(연령·성별·캠페인·소재별) 데이터를 그대로 반영, 8월 4주차 성과 요약 및 향후 계획 텍스트 포함
- 소재 TOP5: Meta Ads API에서 실시간 조회한 구매/클릭율(CTR)/전환율(CVR) 기준 상위 5개 소재와 실제 썸네일 이미지

## 참고
- 메타 소재 지표는 Meta 표준 구매(omni_purchase) 기준으로 집계했습니다. NAVER 협력광고 계정의 "공유 항목 구매(카탈로그 세그먼트)" 필드는 현재 연결된 Meta Ads 도구에서 조회가 불가능해, 두 계정 모두 표준 구매 지표로 통일해 산출했습니다.
- 소재 썸네일은 Meta CDN 실시간 링크(URL)를 그대로 사용하므로, 발급 후 며칠이 지나면 만료되어 이미지가 깨질 수 있습니다.
- 나머지 모든 채널별 수치(월별/주차별/일자별/세부)는 제공해주신 구글시트 원본 값을 그대로 사용했습니다.
