# DAYS ON 통합 광고 성과 대시보드 (v9)

메타(협력광고/외부링크) · 구글 · 네이버(SA/GFA) · 애드부스트 광고 성과를 한눈에 보는 정적 대시보드입니다.

## 파일 구성
- `index.html` — 대시보드 전체 (HTML/CSS/JS 단일 파일, 별도 빌드/서버 불필요)

## 주요 기능
- 왼쪽 사이드바: 매체별 메뉴 이동
- 상단 기간 드롭다운: 7월 / 8월 / 8월 1~6주차 전환 시 카드·그래프·표 전체 갱신 (표지는 선택한 기간의 단일 요약만 표시, 7월vs8월 비교 제거)
- 채널별 광고비·ROAS 막대그래프, 8월 광고비 채널 비중 도넛 차트
- **일별 추이 라인 차트**: 8월 한 달 광고비 vs 구매전환매출 흐름
- **캠페인별 성과 표**: 채널별 매출 상위 캠페인 (구글은 원본 시트 수식 오류로 제외, 안내 문구 표시)
- 8월 주차별 광고비 추이 막대그래프
- 소재 성과 TOP5: Meta Ads MCP로 조회한 실제 소재 이미지
  - 계정 841547815503451 (META 협력광고, 공유 구매 성과 기준)
  - 계정 791581078215593 (META 외부링크)

## GitHub Pages 배포 방법
1. `index.html`을 저장소 **루트 경로**에 push
2. **Settings > Pages** → Branch를 `main` (`/root`)으로 설정
3. 1~2분 후 `https://[깃허브아이디].github.io/[저장소명]/` 에서 확인

## 데이터 출처
- 광고주 제공 구글 시트(DAYS ON 통합 리포트)의 채널별 월별/주차별/일자별/캠페인별 비교표
- Meta Ads MCP 실시간 조회 (소재 이미지, 계정 841547815503451 / 791581078215593)

## 참고
- 소재 썸네일은 Meta CDN 실시간 링크(URL에 만료 정보 포함)라 며칠 지나면 깨질 수 있습니다.
- 애드부스트는 8월 4주차부터 상품별 세분화 운영을 시작해 월별/주차별 비교표가 별도 산출되지 않았습니다 (일별 추이는 반영).
- 구글 캠페인별 비교는 원본 시트에 수식 오류(#REF!)가 있어 반영하지 못했습니다.
