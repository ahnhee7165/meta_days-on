# DAYS ON 통합 광고 성과 대시보드

메타(협력광고/외부링크) · 구글 · 네이버(SA/GFA) · 애드부스트 8월 성과를 정리한 정적 대시보드입니다.

## 배포 방법 (GitHub Pages)
1. 이 zip을 풀어서 GitHub 저장소에 push (index.html이 루트에 있어야 함)
2. 저장소 Settings > Pages > Branch를 main으로 설정
3. 몇 분 후 https://[아이디].github.io/[저장소명]/ 에서 확인 가능

## 데이터 출처
사용자가 제공한 구글 시트(DAYS ON 통합 리포트)의 각 채널별 "월별 비교" 표에서
7월 vs 8월 핵심 지표(노출수/클릭수/광고비/구매/구매전환매출/ROAS)를 추출했습니다.
애드부스트는 8월 4주차부터 상품별 세분화 운영을 시작해 월별 비교표가 따로 없어
전월 대비 변화율 텍스트만 반영했습니다.

## 파일 구성
- index.html : 대시보드 (다크모드 토글, 채널별 탭)
- data.json  : 추출한 원본 수치 데이터 (참고용, index.html에는 별도로 인라인 되어 있음)
